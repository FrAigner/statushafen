# Name "Statushafen" / Name and branding

Deutsch zuerst, English below.

## Deutsch

Der Quellcode von Statushafen steht unter der [MIT-Lizenz](LICENSE). Die MIT-Lizenz regelt den
Quellcode, **nicht** den Namen „Statushafen“ und das Logo. Dafür gilt:

- **Erlaubt:** den Namen für unveränderte Versionen zu verwenden, sowie in Hinweisen wie „basiert auf
  Statushafen“ oder „kompatibel mit Statushafen“.
- **Eigener Name nötig**, wenn du den Code wesentlich änderst oder ein Konkurrenzprodukt oder einen
  gehosteten Dienst anbietest. Dann nimm einen anderen Namen und ein anderes Logo, damit niemand dein
  Produkt mit dem Original verwechselt, und nenne das Original als Quelle.
- Dein Fork soll nicht den Eindruck erwecken, er sei das offizielle Projekt oder werde von dessen
  Autoren betrieben oder empfohlen.

Der Copyright-Hinweis der MIT-Lizenz bleibt in jedem Fall erhalten.

## English

The source code of Statushafen is released under the [MIT License](LICENSE). The MIT License covers
the source code, **not** the name "Statushafen" or the logo. The following applies:

- **Allowed:** using the name for unmodified versions, and in statements such as "based on
  Statushafen" or "compatible with Statushafen".
- **Use your own name** if you change the code substantially or offer a competing product or a hosted
  service. Choose a different name and logo so nobody confuses your product with the original, and
  credit the original as the source.
- Your fork must not suggest that it is the official project or that it is operated or endorsed by its
  authors.

The copyright notice of the MIT License is always kept.
